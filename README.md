# Vasudev Seeram Portfolio

Static portfolio website for Vasudev Seeram, PhD, DABT, ERT.

## Publish With GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root. Do not upload only the zip file.
3. In GitHub, go to `Settings > Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Choose branch `main` and folder `/root`.
6. Save. GitHub will publish the site globally after the Pages build finishes.

Important: `index.html` must be visible directly in the repository root, not inside another folder. The carousel images use root-level files such as `philips-device-bipap.png`, so they can be uploaded directly without relying on image folders.

The live URL will usually be:

`https://<your-github-username>.github.io/<repository-name>/`
